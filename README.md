# Hi, I'm Joyce Liz 👋

### Data Engineer | Analytics Engineer | Python, SQL, PySpark, dbt & Cloud Data Platforms

I'm a Data Engineer with 5+ years of experience building production-grade data products across banking, fintech, technology, and applied research environments.

My work focuses on designing reliable data pipelines, scalable analytical models, automation workflows, and cloud-based data solutions. I have experience connecting data engineering, analytics, and machine learning workflows to support business decisions in high-impact and regulated domains.

I enjoy working across the full data lifecycle: data ingestion, transformation, modeling, validation, documentation, and delivery through analytics products, dashboards, and automated pipelines.
